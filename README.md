# SIDMS – Smart Idle Device Management System

## 🚀 Overview

SIDMS (Smart Idle Device Management System) is an AI-powered web-based prototype developed to reduce unnecessary energy consumption in computer laboratories.

The system continuously monitors computer activity, identifies idle machines, predicts the best power-saving actions using AI, and provides real-time analytics to help educational institutions reduce electricity costs, carbon emissions, and hardware wear.

This project was developed as a prototype to demonstrate how Artificial Intelligence can contribute to sustainable campus infrastructure and smart energy management.

---

## 🎯 Problem Statement

Many computer labs keep systems running even when they are idle, leading to:

- Wasted electricity
- Increased operational costs
- Higher carbon emissions
- Reduced hardware lifespan

SIDMS addresses these challenges through intelligent monitoring and automated power management.
